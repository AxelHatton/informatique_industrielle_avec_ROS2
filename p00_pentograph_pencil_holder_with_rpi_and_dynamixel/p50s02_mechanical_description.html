Description mécanique de la plateforme pantographe

Modèle géométrique

Nous avons : .. math:

\overrightarrow{A_1A_2} + \overrightarrow{A_2A_3} + \overrightarrow{A_3A_4} = \overrightarrow{A_1A_4} + \overrightarrow{A_4A_5}

En projetant sur l’axe \(\overrightarrow{x}\) et \(\overrightarrow{y}\), nous obtenons : .. math:

\begin{aligned}
   \begin{cases}
      l_1 c_1 + l_2 c_2 + l_3 c_3 = l_0 + l_4 c_4 \\
      l_1 s_1 + l_2 s_2 + l_3 s_3 = l_4 s_4
   \end{cases}
   \quad \Longleftrightarrow \quad
   \begin{cases}
      l_1 c_1 + l_2 c_2 - l_0 - l_4 c_4 = -l_3 c_3  \\
      l_1 s_1 + l_2 s_2 - l_4 s_4 = - + l_3 s_3
   \end{cases}
\end{aligned}

Nous avons donc deux équation pour deux inconnues : \(\theta_2\) et \(\theta_3\). \(\theta_1\) et \(\theta_4\) sont les variables d’entrées du mécanisme.

En additionnant les deux équations au carré, nous obtenons une équation sans \(\theta_3\) : .. math:

(l_1 c_1 + l_2 c_2 - l_0 - l_4 c_4)^2 + (l_1 s_1 + l_2 s_2 - l_4 s_4)^2 = l_3^2 \\
\Longleftrightarrow \\
l_1^2 + l_2^2 + l_4^2 + l_0^2 - l_3^2 - 2l_1l_0c_1 - 2l_1l_4c_1c_4 + 2l_0l_4c_4 - 2l_1l_4s_1s_4 + 2c_2l_2(l_1c_1 - l_0 - l_4c_4) + 2s_2l_2(l_1s_1 - l_4s_4) = 0 \\

Nous fixons :

\[ \begin{align}\begin{aligned}\begin{split} M = l_1^2 + l_2^2 + l_4^2 + l_0^2 - l_3^2 - 2l_1l_0c_1 - 2l_1l_4c_1c_4 + 2l_0l_4c_4 - 2l_1l_4s_1s_4\\ L = 2l_2(l_1c_1 - l_0 - l_4c_4) \\ K = 2l_2(l_1s_1 - l_4s_4)\\\end{split}\\Nous obtenons donc l'équation suivante, qui ne dépend que de :math:`\theta_2` :\\.. math::\\\begin{split} M + c_2L + s_2K = 0\\\end{split}\end{aligned}\end{align} \]

Nous pouvons remplacer c2 et s2 par leur expression en fonction de tan(\(\frac{\theta_2}{2}\)) :

\[\begin{split}t = tan(\frac{\theta_2}{2})\\ c_2 = \frac{1 - t^2}{1+t^2}\\ s_2 = \frac{2t}{1+t^2}\\\end{split}\]

Nous obtenons donc :

\[\begin{split}\begin{aligned} L(1-t^2) + 2Kt = - M (1 + t^2)\\ \quad \Longleftrightarrow \quad t^2(M-L)+2Kt + L + M; \end{aligned}\end{split}\]

Nous avons une équation de polynomiale de degré 2, nous pouvons donc calculer t :

\[\begin{split}t = \frac{-2K \pm \sqrt{(2K)^2-4(M-L)(M+L)} - 2K}{2(M - L)}\\\end{split}\]

Ainsi :

\[\theta_2 = 2arctan(t)\]

Avec \(\theta_2\) et connaissant \(\theta_1\), nous pouvons caluler la position X3 et Y3 du point \(A_3\) :

\[\begin{split}X3 = l_1c_1 + l_2c_2\\ Y3 = l_1s_2 + l_2s_2\end{split}\]
